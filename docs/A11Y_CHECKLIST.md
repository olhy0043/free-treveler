# 접근성 수동 점검 체크리스트 (MANUAL-A11Y-CHECK)

REQ-NF-023, REQ-NF-025, REQ-FUNC-079. 이 문서는 자동화할 수 없는 항목을 사람이 직접
브라우저에서 점검하고 결과를 기록하기 위한 템플릿이다. **아직 아무도 점검하지 않았으며,
아래 항목은 전부 `미점검` 상태다.** 실제로 점검한 뒤 각 행의 상태와 비고를 채워 넣는다.

- 상태 값: `PASS` / `FAIL` / `미점검`
- 점검일 / 점검자 / 브라우저·OS·스크린리더 조합을 표에 함께 기록한다.

## 1. 키보드만으로 조작 가능 여부

| 화면 | 흐름 | 상태 | 비고 |
|---|---|---|---|
| `/` | 검색창 포커스 → 여행지 검색 → Tab으로 카드 이동 → Enter로 상세 Drawer 열기 → Esc로 닫기 | 미점검 | |
| `/` | 국가별 주의사항 카드 → Enter로 안전정보 Drawer 열기 → Esc로 닫기 | 미점검 | |
| `/` | 즐겨찾기 버튼에 Tab으로 포커스 → Enter/Space로 토글 | 미점검 | |
| `/travel-tools` | Tab으로 항공/숙소/동행 탭 전환 → 폼 입력 → 제출 버튼까지 키보드만으로 도달 | 미점검 | |
| `/mates` | Filter 입력 → 목록 카드 포커스 이동 → 상세 패널 진입 → 신고 모달 열기/닫기(Esc) | 미점검 | |
| `/account` | 로그인/가입 폼 입력 → 내 글 수정·마감·삭제 버튼까지 Tab 이동 | 미점검 | |
| 전역 | 신고 제출 폼 전체를 키보드만으로 작성·제출 | 미점검 | |
