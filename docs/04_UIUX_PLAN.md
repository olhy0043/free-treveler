# UI/UX Plan — Free Traveler

**Document ID:** UIUX-TRAVEL-001
**기반 문서:** `00_PRD_Travel_v1.md`, `05_SRS_Travel_v1.md`, `PROJECT_SCOPE.md`, `03_UI_COVERAGE_ANALYSIS.md`, `design-reference/vendor/airbnb/DESIGN-airbnb.md`(참고용)
**상태:** v1.0

---

## 1. 개요

Free Traveler는 5개 디자인 Screen(SCR-001~SCR-005)으로 구성된다. Airbnb 디자인 분석 문서는 "흰 캔버스 위에 단일 포인트 컬러를 절제해서 쓰는 방식", "부드럽게 둥근 모서리", "사진 중심의 시각적 무게", "카드 밀도와 여백의 대비"라는 레이아웃 원리만 참고하며, Airbnb의 브랜드 컬러(#ff385c)·서체·로고·와드마크·상표성 문구는 사용하지 않는다. Free Traveler는 코랄 포인트 컬러와 Inter 기반 서체 체계를 독자적으로 정의한다.

## 2. 공통 디자인 시스템

### 2-2. 타이포그래피

기본 서체: `Inter, 'Apple SD Gothic Neo', 'Malgun Gothic', system-ui, sans-serif`. 한글 본문은 시스템 한글 폰트로 자연스럽게 대체된다.

| 토큰 | 크기/굵기 | 용도 |
|---|---|---|
| `type-display-lg` | 32px / 700 | Hero 제목 |
| `type-display-md` | 24px / 700 | Section 제목 |
| `type-title` | 18px / 600 | 카드 제목, 탭 라벨 |
| `type-body` | 16px / 400 | 본문 |
| `type-body-sm` | 14px / 400 | 카드 메타, 보조 설명 |
| `type-caption` | 13px / 500 | 배지, 라벨 |
| `type-button` | 16px / 600 | 버튼 라벨 |

### 2-3. 간격·형태·그리드

- 간격 스케일: 4 / 8 / 12 / 16 / 24 / 32 / 48px
- Desktop 콘텐츠 최대 폭: **1200~1280px**(1440px 캔버스 기준 좌우 여백 자동 확보)
- Section 상하 여백: Desktop **64~96px**, Mobile **40~64px**
- 모서리 반경: 버튼/입력 8px, 카드 14px, Chip·Pill 9999px
- 카드 그리드 간격: Desktop 24px, Mobile 16px(1열)
- 그림자: 카드 hover에 한정한 단일 톤(`0 1px 2px rgba(0,0,0,.06), 0 4px 10px rgba(0,0,0,.08)`), 평면 카드는 1px 헤어라인만 사용

### 2-4. 반응형 기준

| 기준 | 폭 | 비고 |
|---|---|---|
| Desktop | 1440px | 콘텐츠 최대 폭 1200~1280px, Card Grid 3~4열, Header 전체 메뉴 노출 |
| Mobile | 390px | Card 1열, Header는 로고+햄버거, Section 여백 축소 |

두 기준 사이는 열 수를 단계적으로 줄이는 방식으로 보간하며 줄바꿈 대신 열 수 축소를 우선한다.

### 2-5. 접근성·상호작용 공통 규칙

- 모든 인터랙티브 요소의 터치 영역은 최소 44×44px을 확보한다.
- 키보드 포커스는 2px 코랄 또는 잉크 색 아웃라인을 항상 표시하며 `outline: none`만 적용하지 않는다.
- 오류·경고·안전정보 배지는 색상과 텍스트 라벨을 함께 사용한다.
- 모달/Drawer는 열림 시 포커스를 이동시키고 `Esc`로 닫히며 배경 스크롤을 잠근다.

### 2-6. 공통 Header/Footer

5개 Screen 모두 동일한 Header/Footer를 사용한다.

**Header**
- 좌측: Free Traveler 로고(텍스트 워드마크)
- 중앙/우측 내비게이션: 메인, 여행 도구, 동행 찾기, 대표 소개
- 우측 끝: 로그인 전 "로그인" 텍스트 버튼, 로그인 후 계정 아바타/이니셜 버튼(→ SCR-005)
- Mobile: 로고 + 햄버거 메뉴로 축소, 내비게이션은 전체화면 시트로 펼쳐짐

**Footer**
- 3개 컬럼(서비스 소개, 이용 안내, 정책·문의)과 하단 법적 고지 밴드(저작권, 이용약관, 개인정보 처리방침, 콘텐츠 면책 안내)
- Mobile은 1컬럼으로 접힘

### 2-7. 콘텐츠 배치 원칙

- 모든 Screen은 Header와 Footer 사이에 목적이 분명한 Section을 순서대로 배치하고, 같은 형태의 Card Section만 반복하지 않도록 Hero·Card Grid·좌우 분할·Chip 목록·단계 안내·CTA Banner를 교차 사용한다.
- Hero는 뷰포트 전체 높이를 차지하지 않게 만들어 1440px 화면에서 다음 Section의 시작 부분이 함께 보이도록 한다.
- 모든 Section은 제목, 1~3문장의 설명, 실제 콘텐츠 또는 명확한 CTA를 함께 갖춘다.
- "준비 중", "정보 확인 필요" 같은 자리표시 문구나 Lorem ipsum, 의미 없는 빈 카드를 두지 않는다.
- 데이터가 없는 목록도 안내 문장·이용 방법·다음 행동 CTA가 있는 Empty State로 대체해 빈 화면처럼 보이지 않게 한다.
- 모든 이미지는 실제 장소·상황을 설명하는 대체텍스트를 갖는다(예: "제주 성산일출봉 전경").

## 3. SCR-001 `/` 메인

**목적:** 국내·해외 여행지를 발견하고, 여행 동기·안전정보·동행·대표 소개로 자연스럽게 이어지는 시작점.

| # | Section | 컴포넌트 패턴 | 내용 요약 |
|---|---|---|---|
| 1 | 여행지 검색 Hero | Hero + 검색 입력 | "어디로 떠나볼까요?" 톤의 제목과 한 문장 설명, 여행지 키워드 검색창, "여행 조건 정리하기" 버튼으로 `/travel-tools` 이동. Hero 높이는 뷰포트의 절반 수준으로 제한 |
| 2 | 국내 인기 여행지 | Card Grid(6) | 서울·부산·제주 등 국내 여행지 카드 6개, 카드 클릭 시 같은 화면에서 여행지 상세 Drawer 오픈 |
| 3 | 해외 인기 여행지 | Card Grid(6) | 도쿄·방콕·파리 등 해외 여행지 카드 6개, 카드에 국가 배지 표시, 클릭 시 상세 Drawer |
| 4 | 여행 동기·테마 | Chip/Card 목록(6) | "휴양", "액티비티", "미식", "문화유산" 등 테마 칩, 선택 시 SCR-001 목록 필터에 반영 |
| 5 | 국가별 주의사항 | Card Grid(6) + Drawer 연결 | 소개 국가 중 6개의 안전정보 요약 카드(경보 단계·최종 확인일 배지), 클릭 시 안전정보 Drawer로 원문 출처·긴급연락처까지 확인 |
| 6 | 최근 동행글 | Card(최대 3) 또는 Empty State | 데이터가 있으면 최근 모집글 3개 카드, 없으면 "아직 등록된 동행글이 없어요" 설명 + 참여 방법 안내 + "동행 글 작성하기"(`/travel-tools` 동행 탭) CTA |
| 7 | free_traveler 소개 요약 | 좌우 분할 CTA Banner | 대표 사진, "50+ Trips · 30+ Countries" 지표, 한 문장 소개, "대표 이야기 더 보기"(`/about`) CTA |

**Drawer/Modal:** 여행지 카드 선택 시 우측 Drawer(모바일은 하단 시트)로 소개·일정·예산·교통·음식·에티켓·출처를 표시하고, 해외 여행지는 내부에 "국가별 주의사항 보기" 버튼으로 안전정보 Drawer를 이어서 연다.

**상태**

| 상태 | 적용 위치 | 표현 |
|---|---|---|
| Loading | Section 2·3·5·6 | 카드 스켈레톤 |
| Success | 전체 | 카드/목록 정상 렌더 |
| Empty | Section 6 | 안내 문장 + 이용 방법 + 작성 CTA |
| Error | Section 2·3·5 | "여행지 정보를 불러오지 못했어요" + 다시 시도 버튼 |

## 4. SCR-002 `/about` 대표 소개

**목적:** free_traveler의 경험과 철학을 보여주고 콘텐츠 신뢰의 근거를 제공한다.

| # | Section | 컴포넌트 패턴 | 내용 요약 |
|---|---|---|---|
| 1 | 대표 소개 Hero | Hero(사진+텍스트) | 대표 사진과 "여행은 목적지가 아니라 속도를 맞추는 일입니다" 같은 한 문장 소개 |
| 2 | 여행 지표 | 통계 Card 3개 | "50+ Trips", "30+ Countries", "15개국 안전정보 직접 정리" 등 카드형 지표 |
| 3 | 소개·철학 | 좌우 분할 텍스트 | 자기소개, 여행을 시작한 이유, 여행 철학을 2~4개 문단으로 서술 |
| 4 | 여행 Timeline | 세로 Timeline(6개 이상) | 연도·장소·한 줄 요약으로 구성된 대표 여행 이력 |
| 5 | 방문 국가 | 권역별 Chip/목록 | 아시아·유럽·북미·오세아니아 등 권역으로 묶은 30개 이상 방문 국가 |
| 6 | 여행 사진 Gallery | 사진 Grid(8장 이상) | 서로 다른 장소의 사진과 장소를 설명하는 대체텍스트("리스본 트램 거리" 등) |
| 7 | 기억에 남는 여행지 | Card Grid(4) + CTA Banner | 대표가 꼽은 여행지 4개 카드(→ SCR-001 상세 Drawer 연결), "여행 조건 정리하기"(`/travel-tools`)와 "동행 찾아보기"(`/mates`) CTA |

**상태**

| 상태 | 적용 위치 | 표현 |
|---|---|---|
| Loading | Section 4·6 | 이미지/타임라인 스켈레톤 |
| Success | 전체 | 정적 콘텐츠 정상 렌더(운영상 별도 Empty/Error 상태 없음) |

## 5. SCR-003 `/travel-tools` 통합 여행 준비

**목적:** 항공·숙소 조건을 정리해 외부 사이트로 이동하거나 동행 모집글을 작성한다. 세 탭은 입력·검증·완료 상태를 서로 완전히 분리해서 관리한다.

| # | Section | 컴포넌트 패턴 | 내용 요약 |
|---|---|---|---|
| 1 | 이용 안내 Intro | 텍스트 Intro | 페이지 목적과 "조건을 입력하고 요약을 확인한 뒤 외부 사이트로 이동합니다"라는 이용 순서 3단계 요약 |
| 2 | 도구 선택 탭 | Tab | 항공편 / 숙소 / 동행 구하기 3개 탭 |
| 3 | 조건 입력 Form | Form(탭별 개별 상태) | 항공·숙소 탭: 국가·지역·출발일(체크인)·귀국일(체크아웃) 입력. 동행 탭: 이 Section은 작성 Form으로 대체 |
| 4 | 요약 & 외부 이동 | Action Card | 입력 요약 카드 + "항공편 보러 가기"/"호텔 보러 가기" 버튼(새 탭 이동), 동행 탭에서는 해당 없음 |
| 5 | 비전달 고지 & Tip | 고지 배너 + Chip 3개 | "입력하신 조건은 외부 사이트로 전달되지 않습니다" 고지, 항공·숙소 이용 Tip 3개 |
| 6 | 동행 구하기 | 로그인 안내 Card 또는 작성 Form | 비로그인/미성년: "로그인하고 성인 확인을 완료하면 작성할 수 있어요" 안내 + 계정 이동 CTA. 인증 완료: 모집글 작성 Form + 공개 연락처 금지·안전수칙 동의 안내 |

**상태**

| 상태 | 적용 위치 | 표현 |
|---|---|---|
| Success | 항공/숙소 탭 요약, 동행 작성 완료 | 요약 카드, 제출 완료 Toast |
| Error | 항공/숙소 탭 입력 검증, 외부 URL 실패, 동행 작성(연락처 탐지) | 필드별 오류 메시지, "현재 외부 사이트에 연결할 수 없어요" 재시도 안내 |
| Unauthorized | 동행 탭 | 로그인/성인확인 안내 Card로 대체(작성 Form 비노출) |

## 6. SCR-004 `/mates` 동행 조회

**목적:** 조건에 맞는 동행 모집글을 찾아 참가를 요청하거나 신고·차단한다.

| # | Section | 컴포넌트 패턴 | 내용 요약 |
|---|---|---|---|
| 1 | 동행 찾기 Intro | 텍스트 Intro + CTA | 동행 서비스의 목적(공개 연락처 없는 안전한 첫 연결) 설명, "동행 글 작성하기"(`/travel-tools` 동행 탭) CTA |
| 2 | 검색 Filter | Filter + 결과 요약 텍스트 | 국가·지역·기간·모집 상태 필터, "총 N개의 동행을 찾았어요" 요약 |
| 3 | 모집글 목록 | Card 목록(우선 최대 8개) | 데이터가 있으면 카드 형태로 최대 8개 우선 노출, 이후 더 보기로 확장 |
| 4 | 목록·상세 레이아웃 | 좌우 분할(Desktop) / Drawer(Mobile) | Desktop은 좌측 목록·우측 상세 패널 동시 표시, Mobile은 목록에서 선택 시 하단 상세 Drawer |
| 5 | 참가 신청 방법 | 3단계 안내 | "모집글 확인 → 참가 메시지 보내기 → 승인 알림 받기" 3단계 카드 |
| 6 | 안전 이용 안내 | 안내 배너 + CTA | 신고·차단 방법과 개인정보 보호 원칙 안내, "여행 조건도 함께 정리해보세요"(`/travel-tools`) CTA |

**상세 패널 구성:** 제목, 조건(국가/지역/기간/모집인원/스타일), 설명, 작성자 표시, 참가 메시지 입력 Form, 신고·차단 버튼.

**상태**

| 상태 | 적용 위치 | 표현 |
|---|---|---|
| Loading | Section 3 | 카드 스켈레톤 |
| Success | 전체 | 목록·상세 정상 렌더 |
| Empty | Section 3 | "조건에 맞는 동행이 아직 없어요" + 필터 초기화 버튼 + 글쓰기 CTA + 이용 방법 안내 |
| Error | 참가 신청/신고 제출 | 인라인 오류 메시지("잠시 후 다시 시도해 주세요") |
| Unauthorized | 참가 신청·신고·차단 시도 | 로그인/성인확인 필요 안내로 계정 화면 이동 유도 |

## 7. SCR-005 `/account` 계정·관리

**목적:** 로그인부터 프로필, 내 동행 활동, 최소한의 운영자 기능까지 한 화면의 탭으로 관리한다. 역할에 없는 탭은 렌더링하지 않는다.

### Guest 탭 구성

| Section | 내용 |
|---|---|
| 계정 기능 Intro | 로그인하면 이용할 수 있는 기능(동행 글 작성, 참가 요청, 즐겨찾기 동기화 등) 소개 |
| 인증 Card | 로그인 / 회원가입 / 비밀번호 재설정 3개 Card |
| 로그인 후 기능 안내 | 로그인 이후 펼쳐질 프로필·내 활동 탭 미리보기 |
| 보안 안내 | 이메일 인증과 성인 확인이 필요한 이유, 개인정보 최소 수집 원칙 안내 |

### Member 탭 구성

| Section | 내용 |
|---|---|
| 프로필·성인 확인 요약 | 닉네임·연령대·여행 스타일·성인 확인 상태 카드, 편집 진입점 |
| 내 글 | 작성한 모집글 목록(상태 배지: 모집중/마감), 수정·마감·삭제, "새 동행글 작성" CTA |
| 참가 요청 | 내가 보낸 요청 + 내 글에 들어온 요청(승인/거절 액션) |
| 차단 목록 | 차단한 사용자 목록과 해제 버튼 |

### Admin 탭 구성(Member 권한 포함, 관리자 계정에만 노출)

| Section | 내용 |
|---|---|
| 관리 Intro | "신고 처리와 외부 이동 링크만 관리할 수 있어요" 범위 안내 |
| 신고 상태 변경 | 신고 큐(OPEN/REVIEWING/RESOLVED/DISMISSED) 목록과 상태 변경 액션 |
| 외부 URL 설정 | 항공·숙소 외부 이동 URL 입력(HTTPS 허용목록 검증) |

**상태**

| 상태 | 적용 위치 | 표현 |
|---|---|---|
| Loading | 프로필/내 활동/신고 목록 | 스켈레톤 |
| Success | 전체 | 정상 렌더 |
| Empty | 내 글, 참가 요청, 차단 목록, 신고 큐 | 설명 문장 + 다음 행동(예: "아직 작성한 글이 없어요, 지금 첫 동행글을 만들어보세요" + 작성 CTA) |
| Error | 프로필 저장, 로그인/가입 실패 | 필드별 오류 메시지 |
| Unauthorized | Admin 탭 | 관리자 권한이 없는 계정에는 탭 자체를 렌더링하지 않음(오류 화면 대신 탭 비노출로 처리) |

집계형 Dashboard나 통계 시각화는 만들지 않으며, 모든 목록은 카드·표 형태의 단순 나열로 제공한다.
